# Birth Ratio Statistical Analysis

## Overview
This project analyzes historical birth data to investigate patterns in the ratio of male to female births using statistical analysis and resampling techniques.

## Methods
- Data cleaning and exploration
- Data visualization
- Hypothesis testing
- Resampling and simulation
- Statistical interpretation

## Tools
- R
- R Markdown
- ggplot2
- tidyverse

## Files
- `lab05.Rmd` – R code and analysis
- `lab07.pdf` – Completed analysis and visualizations

## Skills Demonstrated
Data analysis, statistical inference, data visualization, and reproducible reporting in R.
